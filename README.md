Deliberate Practice Dashboard
A React-based personal practice organizer for tracking skills, current bottlenecks, and deliberate practice sessions.
The app is designed around a simple learning loop:
Skill → Bottleneck → Practice Session → Observation → Adjustment → Next Session
Features
Skill & Bottleneck Tracking
Create skills such as programming, guitar, or PvP and define a goal and current bottleneck for each one.
Practice Session Logging
Log practice sessions with:
- Practice duration
- What was practiced
- Main mistake
- Discovery or insight
- What to test next
Each session is linked to a specific skill using that skill's ID.

Tech Stack
- React
- JavaScript / JSX
- React Router
- Vite
- CSS

- Installation
Clone the repository and install the dependencies:
npm install
Start the development server:
npm run dev
